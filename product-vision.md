# 1. PRODUCT VISION DOCUMENT

## Historical Events Map — System Vision

---

## 1. Vision Statement

A system that transforms historical and geographical knowledge into an interactive spatial experience, enabling users to explore history through time and location.

It evolves from a simple visualization tool into an AI-assisted knowledge pipeline for structuring and exploring historical data.

---

## 2. Core Idea

The system is fundamentally a **data transformation pipeline**:

> raw historical knowledge → structured events → spatial visualization

The map is only the first interface.

---

## 3. Evolution Path

### Phase 1 — Static Visualization Layer

- Manual dataset
- Single city
- Basic map + filtering

Purpose: Validate core interaction and schema.

---

### Phase 2 — AI Data Construction Layer

- AI generates structured event data
- Converts unstructured text into schema-compliant events
- Adds metadata (tags, enrichment)

Purpose: Introduce AI as a structured data generator.

---

### Phase 3 — External Knowledge Integration Layer

- Wikipedia / external APIs
- Geolocation-based retrieval
- AI transforms raw knowledge into structured events

Purpose: Connect real-world knowledge to structured representation.

---

### Phase 4 — Scalable Knowledge Platform

- Multiple cities
- Multiple datasets
- Flexible exploration modes

Purpose: Generalize system into spatial knowledge platform.

---

## 4. Core Principles

- Everything becomes a structured event
- Data sources are interchangeable
- UI is decoupled from data origin
- AI is an infrastructure layer, not a product feature

---

## 5. Long-Term Constraint

The system must always be reducible to:

> a unified event schema

If this breaks, the system loses coherence.

---

## 6. Non-Goals

- Not a historical encyclopedia
- Not a social platform
- Not a real-time data system
- Not a content marketplace

---

## 7. North Star Outcome

Any location should allow:

- extraction of historical context
- structured representation of events
- interactive spatial exploration
